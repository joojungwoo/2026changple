# 한걸음 — 경계선 지능 아동 교과과정 학습 지원 웹 앱

초등학교 1~3학년 국내 교육과정(2022 개정) 기준 수학·국어 학습 웹 앱.
단원을 **텃밭**으로, 소단원 학습을 **물 주기**로, 회독을 **식물의 성장**으로 보여 줍니다.
화면 흐름은 「한걸음 앱 디자인·기능·플로우 정리」 문서를 따릅니다.

## 화면 흐름

```
스플래시 → 로그인 (학생으로 / 지도자로 탭 · 로그인 상태 유지) · 회원가입 (이름 · 생년월일 · 아이디 · 비밀번호 · 개인정보 동의)

학생
  홈: 강이 흐르는 들판에서 수학 / 국어 고르기        탭바(홈에서만): 게임 · 홈 · 채팅
  → 텃밭: 단원 하나 = 밭 한 칸 (씨앗 → 새싹 → 나무 → 열매)
      복습할 때가 되면 식물이 시들고 "물을 줘ㅠㅠ" 말풍선 → 누르면 물 주기(복습)
  → 소단원 학습: 지금 식물 ➜ 다음 식물 · 💧 물 게이지 · 1-1 · 1-2 · 1-3 · MAX

  5분 동안 터치가 없으면 🌱 운동 시간 (지도자가 학생마다 켜고 끔)
```

## 수파베이스 연결

1. 대시보드 → **SQL Editor**에 `supabase/schema.sql` 전체를 붙여 넣고 **Run** (여러 번 실행해도 괜찮아요).
2. **Authentication → Sign In / Providers → Email**: **Confirm email 끄기**.
   아이디를 `아이디@hangeoleum.app` 모양의 가짜 이메일로 바꿔 가입하므로 메일을 받을 수 없어요.
3. **Project Settings → API**에서 Project URL과 anon(publishable) 키를 `js/config.js`에 넣기.
   service_role(secret) 키는 절대 넣지 마세요.

- 화면 코드는 그대로 `Store`를 바로바로 불러요. 로그인할 때 서버에서 내 정보를 받아 메모리에 두고, 바뀌면 0.8초 모았다가 올립니다(`cloud.js`).
- 학습 기록은 학생마다 JSON 하나(`learning_data`)입니다. 두 기기에서 동시에 공부하면 나중에 올린 쪽이 남습니다.
- 지도자는 맡은 학생의 기록만 읽을 수 있고(RLS), 지도자 화면에 있으면 30초마다 새로 받습니다.
- 수파베이스를 쓰기 전에 이 기기에서 만든 계정은 **같은 아이디 · 비밀번호로 처음 로그인할 때 서버로 옮겨집니다**(학습 기록 · 맡은 학생 포함).
- 비밀번호는 수파베이스 최소 길이(6자)를 넘도록 앞에 `hg:`를 붙여 보냅니다. 아이들은 지금처럼 4자 이상이면 돼요.

> 정적 자원은 `index.html`에서 `?v=N` 쿼리로 캐시를 무효화합니다. CSS/JS를 고친 뒤 화면이 그대로면 이 숫자를 올리세요.

## 계정

- **학생 / 지도자를 따로 가입하고 따로 로그인**합니다. 학생 아이디로 지도자 탭에 로그인할 수 없고, 그 반대도 같습니다.
- 회원가입: 이름 · 생년월일 · 아이디(영어 소문자·숫자 4~20자) · 비밀번호 + 개인정보 수집·이용 동의. 프로필 사진은 없습니다.
- 학생의 학년은 생년월일로 어림해 정하고(1~3학년), 텃밭 화면의 학년 탭에서 바꿔 볼 수 있습니다.
- **로그인 상태 유지**를 켜면 새 탭·다음 방문에도 로그인돼 있습니다. 끄면 그 탭을 닫을 때까지만 유지됩니다.
- 지도자는 **학생 아이디로 학생을 추가**합니다. 한 지도자가 여러 학생을 맡을 수 있습니다(상담실·학교).

## 텃밭 규칙

| 요소 | 규칙 |
|---|---|
| 💧 물 게이지 | 소단원 수만큼 칸이 있어요. 소단원의 문제를 **모두 한 번 이상** 풀면 한 칸이 차요 |
| 🌰 씨앗 | 단원에서 문제를 한 문제라도 풀면 씨앗을 심어요 |
| 🌱 새싹 (1회독) | 물 게이지가 가득 차면(모든 소단원 완료 또는 MAX 통과) |
| 🌳 나무 (2회독) | 1회독 **하루 뒤**부터 소단원 화면에 "2회독 하고 나무로 키우기" 버튼이 생겨요 |
| 🍎 열매 (3회독) | 2회독 **일주일 뒤**부터 3회독을 할 수 있어요 |
| 회독 퀴즈 | **소단원마다 7문제**. 회독마다 문제가 바뀌어요(아래 「회독마다 바뀌는 문제」) |
| 🥀 시들기 | 복습할 때가 되면 식물 색이 바래고 "물을 줘ㅠㅠ" 말풍선이 떠요 |
| 💧 물 주기(복습) | 시든 식물을 **원래대로 돌려놓기만** 해요. 자라는 것은 스스로 다시 공부(회독)했을 때만 |
| ⚡ MAX | 학교에서 이미 배웠다면 **교과서 문제 10개**로 소단원을 건너뛰어요. **80% 이상**이면 물이 가득. 힌트 없음 |
| 🔒 MAX 잠금 | 80% 미만이면 틀린 문제의 소단원을 빨갛게 표시하고 MAX를 잠가요. 표시된 소단원을 다시 끝까지 풀면 열려요 |

복습 탭(복습 상자)은 없앴고, 복습은 텃밭의 물 주기로 합쳤습니다.

### 언제 시드나요

- **틀린 문제**: 다음 날이 복습 날입니다. 맞힐 때마다 `1일 → 3일 → 7일 → 14일 → 30일`로 늘어나고, 다시 틀리면 처음으로 돌아갑니다.
- **단원 복습**: 1회독을 마친 단원은 틀린 문제가 없어도 `3일 → 7일 → 14일 → 30일` 간격으로 물을 줘야 합니다.
- 물 주기 한 번은 복습 날이 된 틀린 문제(최대 10개)이고, 5문제가 안 되면 그 단원의 새 문제로 채웁니다.
- 시든 동안에는 회독 버튼 대신 물 주기 버튼이 나옵니다(먼저 물을 줘야 자랄 수 있어요).

> 간격은 자문 후 확정할 예정입니다. `js/store.js` 맨 위의 `SRS_INTERVALS` · `REVIEW_INTERVALS` · `PASS_INTERVALS` · `PASS_PER_SUB` · `MAX_PASS_RATE`만 바꾸면 됩니다.

### 회독마다 바뀌는 문제

- **1학년 수학(5단원 모두)**: `js/gen.js`의 문제 틀이 수준은 같고 숫자·물건이 다른 문제를 매번 새로 만듭니다.
  문제 id가 `단원~소단원~틀~씨앗` 모양이라 id만으로 같은 문제를 다시 만들 수 있습니다(복습 스케줄·기록은 id만 저장).
- **그 밖의 단원(국어, 2·3학년)**: 문제 틀이 아직 없어 문제은행에서 회독마다 다른 자리부터 돌려 뽑고 선택지 순서를 섞습니다.
  소단원에 문제가 7개보다 적으면 있는 만큼만 나옵니다. **문제 재구성 프롬프트로 문제를 더 채우면** 회독마다 완전히 다른 문제가 됩니다.

## 문제

### 단원 구성

| 학년 | 수학 | 국어 |
|---|---|---|
| 1 | 9까지의 수 · 여러 가지 모양 · 덧셈과 뺄셈 · 비교하기 · **50까지의 수** (교과서 「수학 1-1」) | 1학기: 글자를 만들어요 · 받침이 있는 글자를 읽어요 · 낱말과 친해져요 · 반갑게 인사해요 · 알맞게 띄어 읽어요 / **2학기(「국어 1-2 가」): 기분을 말해요 · 낱말을 정확하게 읽어요 · 그림일기를 써요 · 감동을 나누어요** |
| 2 | 세 자리 수 · 여러 가지 도형 · 덧셈과 뺄셈 · 길이 재기 · 곱셈구구 | 만나서 반가워요 · 말의 재미가 솔솔 · 겪은 일을 나타내요 · 마음을 짐작해요 · 자신의 생각을 표현해요 |
| 3 | 덧셈과 뺄셈 · 나눗셈 · 곱셈 · 길이와 시간 · 분수와 소수 | 재미가 톡톡톡 · 문단의 짜임 · 알맞은 높임 표현 · 내 마음을 편지에 담아 · 중요한 내용을 적어요 |

- 1학년 수학 5단원은 교과서에 맞춰 「시계 보기와 규칙 찾기」(1-2 내용)에서 「50까지의 수」로 바꿨습니다.
- 「국어 1-2 가」 네 단원은 교과서에 소단원이 둘씩이라, 학습 목표에 따라 소단원 셋으로 나눴습니다(`js/bank/k1b.js` 맨 위 참고).

### 문제 유형 (3가지)

**유형과 난이도는 학생 화면에 보여 주지 않습니다.** 지도자 성과 리포트의 유형별 성취도에만 씁니다.

| 유형 | 내용 |
|---|---|
| 시각화형 `visual` | 그림과 구체물을 활용한 개념 이해 |
| 단계분해형 `step` | 문제 해결 과정을 작은 단계로 분리 |
| 고차원적 사고 지원형 `think` | 고차원적인 사고가 필요한 문제를 풀어서 제공 |

예전 문제은행의 네 유형은 `구체물·그림형 → 시각화형`, `단계분해형 → 단계분해형`, `반복회상형·생활맥락형 → 고차원적 사고 지원형`으로 읽습니다(`curriculum.js`의 `TYPE_ALIAS`).
그래서 2·3학년과 국어 1학기는 `think`가 많습니다. 문제 재구성 프롬프트로 다시 만들 때 유형을 고르게 맞추면 됩니다.

### MAX — 교과서 문제

| 단원 | MAX 문제 |
|---|---|
| 1학년 수학 1~5단원 | 교과서 「수학 1-1」 문제 10개 (`js/bank/max-m1.js`) |
| 1학년 국어 2학기 1~4단원 | 교과서 「국어 1-2 가」·「국어활동」 문제 10개 (`js/bank/k1b.js`의 `MAX_BANK`) |
| 그 밖의 단원 | 교과서 원문이 없어 그 단원의 가장 어려운 문제 10개로 대신합니다 |

교과서의 수·낱말·물음은 그대로 두고 답 쓰는 칸만 고르기로 바꿨습니다. 그림은 쓸 수 없어 같은 개수의 그림 글자로 대신했습니다.
문제마다 `src`(교과서 쪽수)와 `sub`(틀렸을 때 다시 공부할 소단원)가 있습니다.

**사람이 한번 봐 주면 좋은 MAX 문제** (교과서 활동이 열린 질문·그림·영상이라 객관식으로 옮기며 손을 댄 것):
`k1-6-x2` `k1-6-x8` `k1-7-x2` `k1-7-x6` `k1-8-x3` `k1-8-x5` `k1-8-x7` `k1-8-x10` `k1-9-x6` `k1-9-x7` `k1-9-x9` `k1-9-x10`,
수학은 수량이 교과서 글에 없어 정한 `m1-4-x1`~`x3`(막대 길이) · `m1-4-x10`(우유갑/페트병 크기).

### 문제 추가하기

- 단원 통째로: `js/bank/k1b.js`처럼 `EXTRA_CHAPTERS`에 단원을, `MAX_BANK`에 교과서 문제 10개를 넣고 `index.html`에 파일을 추가합니다.
- 문제에 `sub`(0·1·2)를 직접 적으면 `subunits.js`에 넣지 않아도 됩니다.
- 숫자가 바뀌는 문제: `js/gen.js`의 `GENERATORS['단원 id'][소단원]`에 틀(함수)을 추가합니다.

## 성과 리포트 (지도자)

| 항목 | 계산 |
|---|---|
| 독립 해결률 | 힌트 없이 첫 시도에 맞힌 문제 수 ÷ 전체 풀이 문제 수 × 100 |
| 평균 힌트 사용 | 소단원을 한 번 풀 때 힌트를 본 횟수의 평균 |
| 유형별 성취도 | 유형마다 문제 점수의 평균 × 100 (혼자 정답 1 · 힌트 보고 정답 0.5 · 오답 0) |
| 성장 그래프 | 독립 해결률 선 그래프 — 주간: 월~일 / 월간: 1주~4주(29일부터는 4주) / 연간: 1월~12월 |
| 성장 포인트 | 지난 기간보다 독립 해결률이 오르거나, 힌트가 줄거나, 유형 성취도가 오른 것만 긍정적인 문장으로 |

- 기간은 이번 주(월~일) · 이번 달 · 올해이고, 증감은 바로 앞 기간(지난주·지난달·작년)과 비교합니다.
- **유형별 성취도의 점수 식은 임시입니다.** 문서의 "프롬프트에 있는 score"가 받은 프롬프트 파일에 없어서 위 식으로 두었습니다. 정해지면 `store.js`의 `_measure` 안 `scoreOf`만 바꾸면 됩니다.
- 문제는 한 번에 한 번만 답할 수 있어서 "첫 시도"는 그 문제의 답과 같습니다.

## 문제 풀이 구조 (느린학습자 맞춤)

같은 문제를 아이마다 다른 모습으로 보여 주고 다른 방법으로 답하게 하려고 세 층으로 나눴어요 (`js/problem.js`).

| 층 | 하는 일 |
|---|---|
| 문제 데이터 | 기존 문제를 `Problem.from(q)`로 감싸요. 보기가 모두 같은 단위의 수면 숫자로 답할 수 있어요(`answer.kind = 'number'`). `27 + 15 = ❓` · 세로셈을 읽어 계산이 정답과 같으면 `math: {a, b, op}` |
| 표현 방식 `REPS` | 숫자(국어는 글자) · 그림(덧셈·뺄셈 20 이하) · 듣기. 블록은 Phase 2. 저마다 `supports(p)`로 할 수 있는 문제를 골라요 |
| 입력 방식 `INPUTS` | 터치 선택 · 숫자패드 · 손글씨(Phase 2). 안 되는 문제면 손글씨 → 숫자패드 → 터치 선택으로 넘어가요 |
| 판정 `judge()` | 입력 방식과 상관없이 한 곳에서 문제 데이터로 판정해요 |

- 퀴즈 화면(`screenQuiz`)은 하나예요. 모드 · 표현마다 화면을 따로 만들지 않아요. 문제 위의 버튼으로 숫자 ↔ 그림 ↔ 듣기를 바꿔 볼 수 있어요.
- **오답**: ❌ · 빨간색 없이, 고른 답에 맞는 도움말(🤔)을 보여 주고 한 번 더 고르게 해요. 기록은 첫 답만 남겨요(독립 해결률). MAX는 다시 고르지 않아요.
  도움말은 문제의 `why[보기 번호]`가 있으면 그것, 없으면 수의 차이로 흔한 실수를 짚어요(하나 차이 · 10 차이 · 자리 바꿈 · 더하기/빼기 바꿈 · 문제의 수 그대로).
- **화면 배치**: 넓은 가로 화면이면 왼쪽 문제 · 오른쪽 풀이, 세로면 위 · 아래. 회전해도 다시 그리지 않아 풀던 상태가 그대로예요.
- 학습 기록에 `rep`(본 방법) · `input`(답한 방법) · `ms`(걸린 시간)를 함께 남겨요.

### ⚙️ 설정 (보호자)

- 홈의 ⚙️를 **3초 동안 꾹** 누른 뒤 계산 문제를 풀어야 들어가요. 바꾸면 바로 저장 · 반영돼요(학습 기록의 `profile`에 저장 → 수파베이스로 기기 간 유지).

## 채팅 · 운동 시간 · 게임

### 💬 채팅 (`js/chat.js`)

- **항상 1대1**. 가입한 학생이면 학교·기관이 달라도 누구와나 이야기할 수 있습니다.
- **홈 화면 탭에서만** 들어갑니다. 새 말이 오면 채팅 탭 위에 빨간 점이 뜨고, 공부 화면에는 버튼도 알림도 없습니다.
- 채팅 탭: **현재 접속 중인 친구** 목록 → [채팅하기]. 이미 이야기한 친구는 안 읽은 말의 수를 보여 줍니다.
- 채팅방: **새싹이의 추천 주제**("~에 대해 이야기해 볼까요?" · "~ 물어보세요!"). 추천일 뿐이라 자유롭게 이야기해도 됩니다.
  지금은 준비해 둔 주제 10개를 돌려 보여 줍니다. AI 챗봇을 붙일 때는 `ChatBot.topic`만 바꾸면 됩니다.
- 나쁜 말 가리기는 예전의 단어 목록 방식만 남겼습니다. AI 필터, 인증코드, 신고·차단·관리자 기능은 베타 이후입니다.

- **전송**: 수파베이스가 연결되어 있으면 `ChatCloud` — 메시지는 `messages` 표, 새 메시지는 Realtime, 접속 중인 친구는 Presence(`online` 채널).
  주고받은 두 사람만 읽을 수 있고, 학생끼리만, 자기 이름으로만, 1초에 한 번만 보낼 수 있어요(RLS · 트리거). 읽은 위치(`chat_reads`)도 서버에 남아 다른 기기에서도 빨간 점이 맞아요.
- 연결 정보가 없으면 `ChatLocal` — 같은 기기의 탭끼리만 이야기할 수 있어요(개발용).
- 한 기기에서 탭마다 다른 학생으로 로그인할 수 있어요(로그인 정보를 탭마다 따로 둠).

### 🌱 운동 시간 (`js/motion.js`)

- 문의하기: 수파베이스 `inquiries` 표에 쌓이고, 대시보드에서 봅니다. 알림은 학생 기록에서 만든 목록이고 푸시 알림은 아닙니다.
