# 한걸음 — 경계선 지능 아동 교과 연계 보충학습 · 친구 사귀기 시뮬레이션

초등학교 1~3학년 국내 교육과정(2022 개정) 수학 · 국어. 「개편 후 최종 보고서」의 **친구 사귀기 학교생활 시뮬레이션**을 구현했어요.
대단원 하나 = 새 친구 한 명. 친구와 이야기하며 개념을 배우고, 이야기 속 문제를 풀고, 숙달 기준에 닿으면 친구가 돼요.
화면 디자인은 「창플 포스터 + 화면 수정」 그대로(그림은 포스터에서 뽑은 도트 그림 `assets/school/`).

```

학생
  처음 한 번: 레벨 테스트 10문항 (지금 학년까지의 교과서 수준) → 과목마다 학습 시작점(학년 · 학기)

  복도(홈): 수학 · 국어 교실 문. 빨간 화살표 = 오늘 갈 교실. ⚙ 설정 · ⏏ 로그아웃
  → 교실: 단원마다 친구 자리

  → 대화: 친구 큰 그림 + 이름표 대화 상자 ▶ / 사회성 선택지(인사 · 거절 · 공감 · 협력 · 갈등 해결) / 개념 카드

       첫 시도에 틀리면 친구가 격려하고 이유를 짚어 준 뒤 한 번 더. 맞히면 친구가 노력 · 과정을 칭찬해요.
  → 기준 도달 → "○○와 친구가 됐어!"   어디서나 "잠깐 쉬는 시간!" → 그 자리부터 이어서

지도자 (학부모 · 선생님)
  학생 리스트(+ 학생 아이디로 추가) · 알림 · 문의하기
  → 학생 설정: 학습 수준(레벨 테스트 결과 확인 · 학년 · 학기 바꾸기) · 친구가 된 단원과 복습 날
  → 성과 리포트: 독립 해결률 · 힌트 사용 변화 · 유형별 성취도 · 성장 그래프(주 · 월 · 년) · 성장 포인트
                 + 유형별 제공 비율 · 개념별 숙달도/신뢰도 · 사회성 연습 기록
```

## 개인화 규칙 (보고서 2.2.7 · 2.2.8 · 4.3.2 — `js/mastery.js`의 MASTERY_RULES 한 곳에서 조정)

| | |
|---|---|
| 숙달도 | 최초 `M = 100 × (0.50A + 0.25H + 0.1875T + 0.0625S)` · 복습 후 `M = 100 × (0.40A + 0.20H + 0.15T + 0.20R + 0.05S)` |
| 신뢰도 | 최초 `C = 100 × (N+V+D+H+K+S) ÷ 6` · 복습 후 `÷ 7` (+P). LOW < 40 ≤ MEDIUM < 70 ≤ HIGH |
| 친구 되기 | 모든 개념 M ≥ 75 · C ≥ 70 · 힌트 없이 푼 변형 문제 · 미해결 반복 오답 없음. 미달이면 재설명 · 변형 문제를 대화 사이에 넣고, 끝에서 미달 개념만 한 번 더 |
| 다음 행동 | 숙달·신뢰 높음 → 다음 개념 / 숙달↑신뢰↓ → 다른 유형 확인 문제 / 숙달↓신뢰↑ → 재설명 + 단계 문제 / 둘 다↓ → 진단 문제 |
| 유형 비율 | 시각화 · 단계분해 · 고차원 사고 33.3%씩 → 유형마다 5문항마다 비교, +10%p / −5%p, 20~60% |
| 복습 | 친구가 된 다음 날 → 잘 기억하면 1 → 3 → 7 → 14 → 30일, 많이 잊으면 다음 날로 당겨요. 복습은 느낌표로만 시작 |

시연: 주소에 `?local`을 붙이면 서버 없이 이 기기에서만, `?day=3`을 붙이면 사흘 뒤 날짜로 동작해요(복습 느낌표 확인용).

## 수파베이스 연결

1. 대시보드 → **SQL Editor**에 `supabase/schema.sql` 전체를 붙여 넣고 **Run** (여러 번 실행해도 괜찮아요).
2. **Authentication → Sign In / Providers → Email**: **Confirm email 끄기**.
   아이디를 `아이디@hangeoleum.app` 모양의 가짜 이메일로 바꿔 가입하므로 메일을 받을 수 없어요.
3. **Project Settings → API**에서 Project URL과 anon(publishable) 키를 `js/config.js`에 넣기.
   service_role(secret) 키는 절대 넣지 마세요.

- 화면 코드는 그대로 `Store`를 바로바로 불러요. 로그인할 때 서버에서 내 정보를 받아 메모리에 두고, 바뀌면 0.8초 모았다가 올립니다(`cloud.js`).
- 학습 기록은 학생마다 JSON 하나(`learning_data`)입니다. 두 기기에서 동시에 공부하면 나중에 올린 쪽이 남습니다.
- 지도자는 맡은 학생의 기록만 읽을 수 있고(RLS), 지도자 화면에 있으면 30초마다 새로 받습니다.
- 수파베이스를 쓰기 전에 이 기기에서 만든 계정은 **같은 아이디 · 비밀번호로 처음 로그인할 때 서버로 옮겨집니다**(학습 기록 · 맡은 학생 포함).
- 비밀번호는 수파베이스 최소 길이(6자)를 넘도록 앞에 `hg:`를 붙여 보냅니다. 아이들은 지금처럼 4자 이상이면 돼요.

- **화면 크기**: 태블릿 · 컴퓨터(폭 700px 이상)에서는 앱이 화면을 꽉 채워요. 배경은 끝까지, 글과 버튼은 가운데 880px 안에 둬요(`--content`). 휴대폰에서는 그대로예요.

> 정적 자원은 `index.html`에서 `?v=N` 쿼리로 캐시를 무효화합니다. CSS/JS를 고친 뒤 화면이 그대로면 이 숫자를 올리세요.

## 계정

- **학생 / 지도자를 따로 가입하고 따로 로그인**합니다.
- 회원가입: 이름 · 생년월일 · 학년(학생, 레벨 테스트 범위) · 아이디(영어 소문자·숫자 4~20자) · 비밀번호 + 개인정보 동의.
- 학생은 처음 들어오면 레벨 테스트부터 해요. 학습 학년 · 학기는 지도자 화면에서만 보이고 바꿀 수 있어요.
- 지도자는 **학생 아이디로 학생을 추가**합니다. 한 지도자가 여러 학생을 맡을 수 있습니다(상담실·학교).
- 지도자가 학습 수준을 바꾸려면 수파베이스에 `supabase/schema.sql`을 **다시 한 번 실행**해야 해요(`profiles.level` · `set_student_level` 추가).

- 「국어 1-2 가」 네 단원은 교과서에 소단원이 둘씩이라, 학습 목표에 따라 소단원 셋으로 나눴습니다(`js/bank/k1b.js` 맨 위 참고).

### 문제 유형 (3가지)

**유형과 난이도는 학생 화면에 보여 주지 않습니다.** 지도자 성과 리포트의 유형별 성취도에만 씁니다.

| 유형 | 내용 |
|---|---|
| 시각화형 `visual` | 그림과 구체물을 활용한 개념 이해 |
| 단계분해형 `step` | 문제 해결 과정을 작은 단계로 분리 |
| 고차원적 사고 지원형 `think` | 고차원적인 사고가 필요한 문제를 풀어서 제공 |

예전 문제은행의 네 유형은 `구체물·그림형 → 시각화형`, `단계분해형 → 단계분해형`, `반복회상형·생활맥락형 → 고차원적 사고 지원형`으로 읽습니다(`curriculum.js`의 `TYPE_ALIAS`).
그래서 2·3학년과 국어 1학기는 `think`가 많습니다. 문제 재구성 프롬프트로 다시 만들 때 유형을 고르게 맞추면 됩니다.

### 문제 추가하기

- 단원 통째로: `js/bank/k1b.js`처럼 `EXTRA_CHAPTERS`에 단원을, `MAX_BANK`에 교과서 문제 10개를 넣고 `index.html`에 파일을 추가합니다.
- 문제에 `sub`(0·1·2)를 직접 적으면 `subunits.js`에 넣지 않아도 됩니다.
- 숫자가 바뀌는 문제: `js/gen.js`의 `GENERATORS['단원 id'][소단원]`에 틀(함수)을 추가합니다.

## 화면에서 지킨 것

- **학년 숨김** — 학생 화면에는 학년 · 학기 · 단원 번호를 쓰지 않아요.
- **실패로 끝나지 않음** — 선택지는 감점이 없고, 틀려도 친구가 격려하며 다시 보여 줘요. 기준에 못 미치면 재설명 · 변형 문제를 더 해서 모두 친구가 돼요.
- **노력 · 과정 칭찬** — "혼자 끝까지 생각했네", "다시 생각한 게 멋져" 처럼 한 일을 구체적으로 말해요.
- **글을 길게 읽지 않아도** — 책상 · 친구 모습(빈자리 · 느낌표 · 앉음 · 자물쇠)과 화살표로 다음 할 일을 보여 줘요.
- 타이머 없음 · `prefers-reduced-motion` 존중 · 설정에서 움직임 끄기.

## 아직 안 한 것

- 친구 그림: 포스터에 있는 두 친구(지아 · 남자아이)를 바탕으로 머리색을 바꿔 8명을 만들었어요. 친구마다 새 그림이 생기면 `js/friends.js`의 `FRIEND_LOOKS`만 바꾸면 돼요. 큰 대화 그림은 지아만 있고, 다른 친구는 작은 그림을 크게 써요.
- 직접 쓴 이야기는 1학기 수학 다섯 단원 + 분식집(세 자리 덧셈)이에요. 나머지 단원은 단원 개념 · 사회성 주제로 이야기를 만들어요.
- 기관 인증 · 전용 로그인, 학생 쪽 승인 없이 지도자가 학생을 추가할 수 있는 점.
- 예전 텃밭 · 채팅 · 운동 시간 · 게임 탭은 보고서 개편(4.5)에 따라 화면에서 뺐어요. (`games/`, `api/topics.js` 파일은 남아 있어요)

## 검증

- `node tools/check-problems.js`: 문제 전수 × 표현 방식 × 입력 방식 렌더링 · 판정, 손글씨 인식기.
- 브라우저(`?local`): 가입 → 레벨 테스트 → 복도 → 교실 → 지아와 대화 · 선택지 · 개념 카드 · 문제(오답 → 격려 · 힌트) → 친구 완성 → `?day=1` 느낌표 → 재회 · 복습 → 다음 복습 날 늘어남,
  자주 틀리는 학생(재설명 카드 · 미달 개념 다시 · 유형 비율 조정), 블록 보기(분식집), 펜슬 모드, 휴대폰 크기, 지도자 학습 수준 바꾸기 · 리포트.
